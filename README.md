# SigmaOS Adium

This repository is currently a minimal `no_std` component identity scaffold. Its library exposes a `Component` named `SigmaOS-adium`.

No instant messaging client, chat protocol, multimedia, or networking behavior is implemented in the current source. The name does not imply compatibility with the former Adium application.

## Build

```sh
cargo check --lib
```
